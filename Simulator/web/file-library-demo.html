📁 G-Code File Library Demo

This demo showcases the complete file management system for the CNC Simulator.

✨ Features

  • ✅ Create, edit, and delete files - Full CRUD operations
  • ✅ Folder organization - Hierarchical project structure
  • ✅ File versioning - Track changes over time
  • ✅ Search and filter - Find files quickly
  • ✅ File statistics - Track storage usage
  • ✅ Download files - Export G-Code for offline use
  • ✅ Tag-based organization - Categorize your files
  • ✅ Public/private files - Control sharing

🔌 API Endpoints

  • GET /api/files - List user's files
  • GET /api/files/search - Search files
  • GET /api/files/stats - Get statistics
  • GET /api/files/:id - Get file details
  • POST /api/files - Create new file
  • PUT /api/files/:id - Update file metadata
  • PUT /api/files/:id/content - Update content (new version)
  • GET /api/files/:id/versions - Get version history
  • DELETE /api/files/:id - Delete file (soft)
  • POST /api/files/:id/duplicate - Duplicate file

Folder Endpoints

  • GET /api/folders - List folders
  • GET /api/folders/tree - Get folder tree
  • GET /api/folders/:id - Get folder details
  • POST /api/folders - Create folder
  • PUT /api/folders/:id - Update folder
  • DELETE /api/folders/:id - Delete folder

💻 Usage Example

// Initialize file library
import { AuthUI } from './js/auth-ui.mjs';
import { FileLibraryUI } from './js/file-library-ui.mjs';

// Create auth system
const auth = new AuthUI();
auth.init();

// Create file library
const fileLibrary = new FileLibraryUI(auth);
fileLibrary.init();

// File library will show automatically when user logs in
// Or manually show: fileLibrary.show();

🐳 Docker Setup

# Start all services (backend with database)
docker-compose up -d

# Initialize database schema
docker-compose exec backend node modules/backend/database/migrations/migrate.mjs init

# Check logs
docker-compose logs -f backend

# Access:
# - Frontend: http://localhost:8080
# - Backend API: http://localhost:8765
# - Health: http://localhost:8765/health
📝 Note: Make sure you're logged in before accessing the file library. The authentication system is required to manage your personal files.
