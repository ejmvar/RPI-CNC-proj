🎨 Theme System

Click the theme toggle button in the top-right corner (🌙/☀️) to switch between light and dark modes. Your preference is automatically saved.

💡 Tip: If you haven't set a preference, the theme follows your system settings automatically.

⚙️ User Preferences

Click the gear icon (⚙️) in the top-right to customize your experience. All settings are saved automatically.

  • Display options (grid, axes, FPS counter)
  • Performance settings (animation speed, camera speed)
  • File options (auto-save)
  • Audio settings (sound effects)

💻 Usage Example

// Initialize all UI enhancement systems
import { ThemeManager } from './js/theme-manager.mjs';
import { KeyboardShortcuts } from './js/keyboard-shortcuts.mjs';
import { UserPreferences } from './js/user-preferences.mjs';

// Initialize theme system
const themeManager = new ThemeManager();
themeManager.init();
window.themeManager = themeManager;

// Initialize keyboard shortcuts
const shortcuts = new KeyboardShortcuts();
shortcuts.init();
window.shortcuts = shortcuts;

// Initialize user preferences
const preferences = new UserPreferences();
preferences.init();
window.preferences = preferences;

// Listen for theme changes
window.addEventListener('themechange', (e) => {
  console.log('Theme changed to:', e.detail.theme);
  // Update 3D scene colors, etc.
});

// Listen for preference changes
window.addEventListener('preferenceschange', (e) => {
  console.log('Preferences updated:', e.detail.preferences);
  // Apply new settings to simulator
});
