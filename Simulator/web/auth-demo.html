🔐 Authentication System Demo

Welcome to the CNC Simulator authentication demo. This page demonstrates the complete user authentication system with registration, login, profile management, and password changes.

Features

  • User registration with email validation
  • Secure login with JWT tokens
  • Profile management (update email and display name)
  • Password change functionality
  • Persistent sessions (localStorage)
  • Automatic token verification
  • Clean modal-based UI
  • Responsive design

API Endpoints

POST /api/auth/register - Register new user

POST /api/auth/login - Login with credentials

GET /api/auth/me - Get current user profile

PUT /api/auth/profile - Update profile

PUT /api/auth/password - Change password

POST /api/auth/logout - Logout

Usage Example

// Initialize authentication UI
const auth = new AuthUI();
auth.init();

// Listen for auth state changes
auth.onAuthChange = (user) => {
  if (user) {
    console.log('User logged in:', user.username);
  } else {
    console.log('User logged out');
  }
};

// Check authentication status
if (auth.isAuthenticated()) {
  const user = auth.getCurrentUser();
  console.log('Current user:', user);
}

Try It Out

Click the Register button in the top-right corner to create an account, then log in to test the authentication system.
